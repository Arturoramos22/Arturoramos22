# Curso gratuito: Contratación estatal y control ciudadano

Invitación y formulario de inscripción para el curso gratuito dirigido a jóvenes sobre contratación estatal y mecanismos de control ciudadano.

## Archivo

- `invitacion.html`: página única con la esquela/invitación y el formulario de inscripción. Es un archivo HTML autónomo (sin dependencias de servidor): se puede abrir directamente en el navegador, subir a GitHub Pages, o enviar como adjunto.

## Cómo funciona el formulario

Al enviar el formulario, se genera automáticamente un correo (vía `mailto:`) dirigido a **abogadosramosmejia@gmail.com** con todos los datos diligenciados, listo para enviar desde el cliente de correo de quien se inscribe. No requiere backend ni servicios externos.

También incluye un botón para copiar un texto corto de invitación, pensado para compartir por WhatsApp o redes.

## Antes de compartirlo

Editar en `invitacion.html` los datos que aún son provisionales:

- Fecha y hora exactas de inicio (sección "Detalles").
- Enlace de la reunión virtual, si ya está definido.
- Número de referencia/radicado, si se quiere usar uno propio.

## Cómo compartirlo

- Enviar el archivo `invitacion.html` directamente, o
- Publicarlo en GitHub Pages para obtener un enlace público, o
- Usar el enlace del artefacto generado en esta sesión de Claude para compartir de inmediato.
