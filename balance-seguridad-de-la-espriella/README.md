# Balance de seguridad: gobierno De la Espriella (ago–oct 2026)

- `hilo.md`: borrador del hilo (24 mensajes) con la tarjeta y la fuente de cada afirmación, más datos de respaldo y lo que no se pudo confirmar.
- `fuentes.md`: índice de las 50 notas de prensa con enlace, fecha y qué prueba cada una.
- `fuentes.json`: las mismas fuentes en formato de datos.
- `capturas/`: 50 tarjetas PNG (1200x675) con el titular de cada nota. Son reproducciones tipográficas, no capturas de pantalla de los sitios; cada tarjeta lo indica al pie.
- `generar_tarjetas.js`: script que regenera las tarjetas desde `fuentes.json` (`node generar_tarjetas.js`, requiere Playwright).
